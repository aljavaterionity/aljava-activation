# Admin Dashboard Upgrade

Planned and aligned with the existing ALJAVA TERIONITY admin dashboard:
- Card management stays inside the Admin Dashboard.
- Card type displays the Product name.
- Activation link is generated per card code.
- No icons in the main menu.
- Status follows activation state (`activated_at`).
- Reset dashboard remains under Settings and requires admin authentication.
- Indonesia / English remains supported.
- Preserve the existing visual style.

Next implementation target: professional card management with search/filter, pagination, card detail, copy activation link, QR, and clear activation status without changing the established design.
